# 弓PvPローグライク 設計案（たたき台）

ROUNDS の「負けた側がカードで強化を選ぶ」ループを、Minecraft の弓戦闘に置き換えたもの。バーチャルオブラウンドからは「短いラウンドを高速で回す」「強化が積み上がって戦い方が変わっていく」感覚を借りる。

---

## 1. ゲームの流れ

| フェーズ | 内容 | 目安 |
|---|---|---|
| ロビー | 参加。モードは **大人数FFA** と **多チーム戦**（2〜8チーム） | — |
| アリーナ転送 | 人数に合ったサイズのアリーナへ、スポーン地点を分散してテレポート | 3秒 |
| ラウンド | 最後の1人（1チーム）が残るまで。脱落者は観戦 | 〜90秒（後半はボーダー縮小） |
| カード選択 | **勝者以外の全員が同時に**3枚から1枚選ぶ。全員が選ぶまで待つ（`/br skip` で締め切り、未選択は自動選択） | 無制限（設定で秒数指定も可） |
| 次ラウンド | アリーナを変えて再開 | — |

### 大人数（数十人〜）向けの調整
- **勝利条件はポイント制**：人数が多いと「5ラウンド先取」は終わらないので、順位とキルでポイントを配り、規定ラウンド数（例：8ラウンド）終了時の合計で優勝を決める。チーム戦はチームの合計。
- **強化の配り方**：勝者以外は全員カードを1枚。下位ほどレア度が上がりやすく、最下位グループは選択肢4枚、などで「負けた人ほど強くなる」を保つ。
- **待ち時間対策**：早く脱落した人が長く待たないよう、ラウンドは短め＋時間経過でボーダー縮小・全員発光。脱落者は観戦（将来的に「ゴースト」で妨害役になる案も）。
- **アリーナ**：参加人数に応じて小・中・大のアリーナから選ぶ。スポーン地点は多めに用意して均等に散らす。
- **チーム戦**：スコアボードのチームで色分け、同士討ちなし、ネームタグの表示制御。

1v1 や少人数でも同じ仕組みでそのまま遊べます（勝者以外＝負けた側だけがカードを取る、になる）。

## 2. 弓の基本メカニクス

- 体力は少なめ（例：ハート5個）で、2〜4発で決着するテンポ。
- 弓・クロスボウのみ。近接はほぼ無効化（剣なし、素手ダメージ0）。
- 矢は無限（Infinity 相当）だが「装填数＋リロード」をプラグインで管理し、カードで弄れる余地を作る。
- 移動：ダッシュ（クールダウン付き）、ダブルジャンプを基本アクションにすると ROUNDS っぽい機動戦になる。
- ブロック破壊・設置は無効。アリーナは固定構造。

## 3. 強化カード例

レア度：コモン / レア / エピック。デメリット付きカードで「尖ったビルド」を作れるのが ROUNDS の面白さなので、多くのカードに小さな代償を付ける。

### 矢の性質
| カード | 効果 | 代償 |
|---|---|---|
| 散弾 | 1回で3本発射（拡散） | 1本あたりダメージ-40% |
| 跳弾 | 壁で1回反射 | 弾速-10% |
| 追尾 | 近くの敵へゆるく曲がる | リロード+20% |
| 爆裂矢 | 着弾で小爆発（地形破壊なし） | 装填数-1 |
| 貫通 | 敵とブロック1枚を貫通 | — |
| 重力無視 | 矢が真っすぐ飛ぶ | ダメージ-15% |
| 毒矢 | 命中で毒2秒 | — |
| 雷矢 | 命中地点に落雷（エピック） | リロード+50% |

### 射撃テンポ
| カード | 効果 | 代償 |
|---|---|---|
| 速射 | 引き絞り時間-40% | ダメージ-20% |
| 大容量 | 装填数+3 | リロード+30% |
| フルチャージ | 最大まで引くとダメージ+60% | 引き絞り時間+30% |

### 生存・機動
| カード | 効果 | 代償 |
|---|---|---|
| 頑丈 | 最大体力+2ハート | 移動速度-10% |
| 吸血 | 与ダメージの30%回復 | 最大体力-1ハート |
| 盾 | 右クリックで1秒無敵（CD 6秒） | — |
| ブリンク | ダッシュが短距離テレポートに | — |
| ジェット | 空中ジャンプ+1 | — |
| 透明化 | 被弾しない間ずっと半透明 | — |

### ルール改変系（エピック）
| カード | 効果 |
|---|---|
| ゴースト | 矢がブロックをすり抜ける |
| 分裂 | 矢が空中で2本に分かれる |
| 復活 | ラウンド中1回だけ体力1で復活 |

カードは同じものを重ねて取れる（散弾×2で5本発射、など）設計にすると、ビルドの暴れ方が ROUNDS らしくなる。

## 4. アリーナ

- 小さめの対称マップを5〜10個用意し、ラウンドごとにランダム選択。
- 足場・遮蔽物・高低差を重視。落下死あり（奈落）マップも混ぜる。
- 構造は `.schem` か専用ワールドのコピーで管理し、ラウンドごとに状態をリセット。

## 5. Paper での実装方針

**対象**：Paper 26.2（年号バージョン以降の Paper。必要な Java バージョンはビルド時に確認）。

| 領域 | 方針 |
|---|---|
| ビルド | Gradle (Kotlin DSL) + `paper-plugin.yml`、Java |
| ゲーム状態 | `GameManager` → `Match` → `Round` のステートマシン（LOBBY / COUNTDOWN / PLAYING / CARD_PICK / END） |
| 矢の制御 | `EntityShootBowEvent` で弾を差し替え、`ProjectileHitEvent` で跳弾・爆発・分裂。追尾や重力無視は毎tickのタスクで速度ベクトルを補正 |
| プレイヤー能力 | 各カードを `Card` インターフェース（`onShoot` / `onHit` / `onDamaged` / `onTick` などのフック）で実装し、プレイヤーごとの所持カードリストから合成 |
| 数値強化 | 体力・移動速度は Attribute Modifier、その他は自前のステータスオブジェクト |
| カード選択UI | チェスト型インベントリGUI（アイテム＝カード、Lore に説明）。将来リソースパックでカード絵柄 |
| 表示 | Adventure/MiniMessage でタイトル・アクションバー（装填数）・ボスバー（ラウンド時間）・スコアボード（ラウンド数） |
| アリーナ | 専用ワールドを用意し、ラウンドごとに構造を貼り直し（WorldEdit API か自前のスナップショット） |
| 設定 | カードの数値は `cards.yml` に出してバランス調整を楽にする |
| 大人数での負荷 | 追尾矢の索敵は近距離・数tickおきに間引く、散弾の重ね取りに上限、矢は着弾後すぐ消す、プレイヤーごとのカード効果はキャッシュしてイベント毎に再計算しない |

### 最初に作る範囲（MVP）
1. 大人数FFAのラウンド進行（カウントダウン → 戦闘 → 順位・ポイント集計 → 次ラウンド）
2. 勝者以外全員への同時3択カードGUI（時間切れ自動選択）
3. カード10枚程度（散弾・跳弾・速射・頑丈・吸血・ジェットなど）
4. アリーナ1〜2個
5. `/bowpvp start|stop|join` コマンド

その後、多チーム戦、カード追加、マップ追加、リソースパックの順で広げる。
