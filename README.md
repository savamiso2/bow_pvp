# BowRounds

ROUNDS 風のローグライク弓PvP を Minecraft Paper プラグインとして作るプロジェクトです。
ラウンドごとに勝者以外の全員が強化カードを1枚選び、ビルドを積み上げながら戦います。大人数での対戦を前提にしています。

- 設計: [docs/game-design.md](docs/game-design.md)
- 対象: Paper 26.2 / Java 25

## ダウンロード

[BowRounds.jar（最新版）](https://github.com/savamiso2/bow_pvp/releases/latest/download/BowRounds.jar) をクリックするとダウンロードできます。Paper サーバーの `plugins` フォルダに入れて、サーバーを再起動してください。

## ビルド

```
gradle build
```

`build/libs/` に jar ができます。GitHub Actions でも PR ごとにビルドし、jar を成果物として置きます。
`gradle.properties` の `paperVersion` / `apiVersion` は、実際に公開されている paper-api のバージョンに合わせてください。

## 遊び方

### いちばん簡単な始め方

このプラグイン専用のサーバーとして動かす前提です。

1. jar を `plugins/` に入れてサーバーを起動する … 初回起動時に専用ワールド `bowrounds_arenas` へ既製マップ3種とロビーが自動でできます
2. 入ってきた人は全員ロビーに出てきます（ロビーでは無敵・ブロックは触れません）
3. OPが `/br start` … サーバーにいる全員が参加します（観戦モードの人だけ除外）。試合が終わると全員ロビーに戻ります

試合中に入ってきた人はロビーで待ち、次の試合から参加します。

| マップ | 人数 | 内容 |
|---|---|---|
| pillars | 2〜8人 | 小さな石の床と柱。外は奈落 |
| islands | 6〜24人 | 浮島7つを細い橋でつないだマップ |
| colosseum | 16〜200人 | 壁に囲まれた広い砂岩の闘技場 |

人数に合うマップがラウンドごとに選ばれます。

### 自分でアリーナを作る場合

アリーナは専用ワールドに作るのがおすすめです（ラウンド中はそのワールドのワールドボーダーを使います）。

1. `/br setlobby` … 試合後に戻る場所
2. `/br arena create <名前> <最大人数>` … 今いる場所がアリーナの中心
3. `/br arena addspawn <名前>` … スポーン地点を追加（人数分くらい）
4. `/br arena border <名前> <サイズ>` / `/br arena players <名前> <最小> <最大>`
5. 管理者が `/br start`

| コマンド | 内容 |
|---|---|
| `/br status` | オンライン人数と試合状況 |
| `/br cards` | 試合中の全員の能力（カード）一覧を開く |
| `/br start` / `/br stop` | 試合開始・停止（OP） |
| `/br skip` | カード選択を締め切る。選んでいない人は自動で決まる（OP） |
| `/br arena setup` | 既製マップ3種とロビーを建て直す（OP） |
| `/br arena list` / `delete <名前>` | アリーナ一覧・削除（OP） |

数値（体力・装填数・ポイント配分など）は `config.yml` で変更できます。

## 操作

- Tabキー：順位・ポイント・生存/脱落・カード枚数、ラウンドと残り人数、自分の成績をまとめて表示
- Fキー（持ち替え）／本を右クリック：みんなの能力一覧（1人1行で頭の右に取得カードが並ぶ）
- 右クリック長押し：弓を引く（装填数を撃ち切ると自動リロード）
- 左クリック：ガード（0.3秒だけ矢を防ぐ。クールダウン4秒、XPバーが満タンなら使える）。衝撃波・ブリンク・ダッシュなどのカード能力もガードと同時に発動

## カードの絵柄（リソースパック）

カードには専用の絵柄があります（[一覧](resourcepack/preview.png)）。サーバーに入ると「カードの絵柄を表示するリソースパック」を読み込むか聞かれ、許可した人には3Dのカード選択・カード画面・能力一覧がこの絵柄で表示されます。断った人はこれまでどおりバニラのアイテムで表示されます。

パックは GitHub の最新リリース（`BowRounds-pack.zip`）から自動で配られるので、サーバー側の設定は不要です。`config.yml` の `resource-pack` で無効化や必須化（断ったら入れない）ができます。絵柄は `python3 resourcepack/generate.py` で作り直せます。

## カード選択

ラウンドが終わると、勝者以外のまわりに5枚のカードが扇形に浮かび上がります（自分のカードは自分にしか見えません）。見ているカードが光るので、クリックで決定します。制限時間はなく、全員が選び終わると次のラウンドが始まります（放置している人がいたらOPが `/br skip` で締め切れます。時間制限を付けたいときは `match.card-pick-seconds` に秒数を設定）。`config.yml` の `cards.style: menu` にすると、チェスト型の画面で選ぶ方式に戻せます。

## 収録カード（20枚）

Buckshot（散弾） / Ricochet（跳弾） / Quick Reload（速装填） / Big Quiver（大容量） / Tank（頑丈） / Toxic（毒矢） / Laser（重力無視） / Homing（追尾） / Leech（吸血） / Jetpack（空中ジャンプ） / Power Shot（剛弓） / Explosive（爆裂矢） / Pierce（貫通） / Splitter（分裂） / Knockback（ノックバック）

ガード強化：Reflect（反射） / Shockwave（衝撃波） / Quick Guard（ガードCD短縮） / Blink（瞬間移動） / Dash（ダッシュ）
